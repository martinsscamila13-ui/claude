## Campos para substituir (buscar e substituir em todos os arquivos)

| Campo | Trocar por |
|---|---|
| `LINK_CHECKOUT` | Link do checkout Kiwify |
| `LINK_CHECKOUT_COM_CUPOM` | Link do checkout com o cupom aplicado |
| `LINK_LP` | URL da landing page publicada |
| `LINK_AREA_MEMBROS` | Link da área de membros Kiwify |
| `LINK_WHATSAPP` | `https://wa.me/55DDDNUMERO` |
| `LINK_WHATSAPP_GRUPO` | Link do grupo de avisos |
| `LINK_DESCADASTRO` | Link de descadastro da sua ferramenta de e-mail |
| `FOTO_CAMILA.jpg` / `IMAGEM_COMPARTILHAMENTO.jpg` | URLs das suas imagens |
| `PRAZO_ACESSO` | "12 meses" ou "acesso vitalício" |
| `CUPOM_LANCAMENTO` | Código do cupom com prazo real |
| `{{NOME}}` | Variável de nome da sua ferramenta de e-mail (ex.: `{{contact.FIRSTNAME}}` no Brevo) |
| `DEPOIMENTO REAL 1/2/3` | Depoimentos reais e autorizados |

## Cores (trocar pelas da sua marca)
Na `landing-page.html`, edite as variáveis no topo do `<style>`. Nos e-mails, busque e substitua os códigos:
- `#9C4A3A`: cor principal (terracota)
- `#C9A27E`: detalhe (dourado)
- `#FBF6F1`: fundo (nude)
