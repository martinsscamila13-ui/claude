## 2. Campos para substituir

Use `ferramentas/aplicar-valores.py` (ele reconhece `LINK_*`, `FOTO_*`, `IMAGEM_*`, `CUPOM_*`, `PRAZO_ACESSO`, `QUIZ_URL`, `FORM_ACTION_URL`). Os campos novos deste kit **precisam ser acrescentados ao `valores.json`**.

| Campo | Trocar por | Onde aparece |
|---|---|---|
| `LINK_CHECKOUT` | Link do checkout Kiwify | LP, e-mail 07 |
| `LINK_CHECKOUT_COM_CUPOM` | Checkout com o cupom aplicado | e-mail 09 |
| `LINK_LP` | URL da landing page | e-mails 08, 11, 12; copy; quiz |
| `LINK_AREA_MEMBROS` | Área de membros Kiwify | obrigado, e-mails |
| `LINK_OBRIGADO` | URL da página de obrigado | RUNBOOK / Kiwify |
| `LINK_WHATSAPP` | `https://wa.me/55DDDNUMERO` | LP, obrigado, e-mails |
| `LINK_GRUPO_VIP` | Grupo/lista VIP (substitui o antigo campo do grupo de WhatsApp) | obrigado, e-mails 02 e 10 |
| `LINK_DESCADASTRO` | Link de descadastro da ferramenta de e-mail | todos os e-mails |
| `QUIZ_URL` | URL pública do quiz (nos arquivos de `guerrilha/` aparece como `LINK_QUIZ`; no quiz, `LINK_QUIZ_PUBLICO`) | LP (hero, FAQ, rodapé), e-mail 17, copy |
| `FORM_ACTION_URL` | Endpoint do formulário de leads do quiz | `guerrilha/01` |
| `LINK_EBOOK` | Link de download do ebook (Drive "qualquer pessoa com o link" ou hospedagem) | e-mails 10 e 17, copy |
| `LINK_FORM_ENTRADA` | Google Forms do Índice Anti-Exaustão de entrada | guia seção 12 |
| `LINK_FORM_SAIDA` | Google Forms de saída (Índice + depoimento autorizado) | e-mail 06, guia seção 12 |
| `LINK_GPT` / `LINK_GEM` | Links do Assistente Anti-Exaustão (ChatGPT / Gemini) | `ia/assistente-anti-exaustao-instrucoes.md`, guia seção 12 |
| `LINK_PLANTAO` | Link do Zoom/Meet do Plantão (se houver) | e-mail 14 |
| `FOTO_CAMILA.jpg` | Foto principal (vertical) | LP |
| `FOTO_PALCO.jpg` / `MOCKUP_ALICERCE.png` | Foto em palestra/evento e mockup do kit (opcionais) | LP (comentário de personalização) |
| `IMAGEM_COMPARTILHAMENTO.jpg` | Imagem de compartilhamento (1200×630) | LP (`og:image`) |
| `PRAZO_ACESSO` | "12 meses" ou "acesso vitalício" | LP |
| `CUPOM_LANCAMENTO` | Código do cupom com prazo real | e-mail 09 |
| `{{NOME}}` | Variável de nome da ferramenta de e-mail (ex.: `{{contact.FIRSTNAME}}` no Brevo) | todos os e-mails |

| `INDICA-[NOME]` | Cupom de indicação individual | e-mail 06, guia 7.3 |

> Os PDFs (`workbook` e `ebook`) **não têm campos**: os CTAs usam `@martinsscamila` e "mande LUCRO", então estão prontos para publicar. Se mudar algum texto, gere o PDF de novo a partir do HTML (Chrome → Imprimir → Salvar como PDF, A4, gráficos de plano de fundo ligado).

## 4. Decisões pendentes da Camila
1. Plantão Anti-Exaustão ao vivo: sim/não, quantos, para qual turma (LP, e-mail 14).
2. Abatimento do curso na Consultoria para alunas (e-mail 15).
3. Prazo de acesso (12 meses ou vitalício).
4. Regravar a Aula 1 e a Aula 4 em versão "curso" (3–5 min cada) ou usar o aviso em texto.
5. Assistente de IA: criar na conta dela e compartilhar o link (recomendado) ou entregar os arquivos.
6. Aulas 19, 23 e 30: localizar ou gravar (o Workbook já cobre as perguntas dessas aulas).
